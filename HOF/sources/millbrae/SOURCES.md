## 2. Transportation-equivalent Commission

- **No dedicated Transportation, Traffic, or Complete Streets Commission exists.**
  Confirmed via the full commissions/committees list fetched from
  https://www.ci.millbrae.ca.us/382/Commissions-Committees, which lists exactly nine
  bodies: Community Enhancement Advisory Committee, Cultural Arts Advisory Committee,
  Economic Development Advisory Committee, Parks and Recreation Commission, Planning
  Commission, Senior Advisory Committee, Sister Cities Commission, Youth Advisory
  Committee, and Citizen's Oversight Committee. No transportation/traffic body appears
  in this list.
- **What handles transportation matters instead:**
  - **Public Works Department** (https://www.ci.millbrae.ca.us/164/Public-Works) — runs
    a Traffic Calming Program per search snippet (not independently fetched/verified
    beyond the snippet).
  - **Planning Commission/Division** for land-use-adjacent transportation review, e.g.
    the Active Transportation Plan, which has a CEQAnet record:
    https://ceqanet.opr.ca.gov/2021080012
  - **C/CAG** (City/County Association of Governments of San Mateo County) — regional
    coordination body; confirmed a 2025 RFP for the San Bruno–Millbrae El Camino Real
    Multimodal Improvement Study:
    https://ccag.ca.gov/wp-content/uploads/2025/02/2025-2-14-San-Bruno-Millbrae-ECR-Multimodal-Improvement-Study-RFP.pdf
    (funded partly via a $760,000 earmark, per search snippet).
  - **SMCTA** (San Mateo County Transit District/Transportation Authority) — headquartered
    in Millbrae (166 N. Rollins Rd, 5th Floor) per search snippet, but this is a
    **county-level JPA, not a city commission**: https://www.smcta.com/

- **Est. pull effort:** **N/A for a commission portal.** If transportation-policy

## 3. Recently Adopted Housing/Zoning Ordinances & Housing Element Compliance

- **6th Cycle Housing Element (2023–2031):** Confirmed via fetch of
  https://www.ci.millbrae.ca.us/269/Certified-Housing-Element
  - Adopted by City Council **February 27, 2024**.
  - **Certified by HCD March 1, 2024** — the page states HCD "is pleased to find the
    adopted housing element in substantial compliance with State Housing Element Law."
  - Identifies sites for **2,199 housing units** across affordability levels, ~663 more
    than the prior (5th) cycle.
  - Page links the adopted/certified final element, the February 2024 redlined draft,
    prior drafts, and the superseded 5th Cycle (2015–2023) element.
  - Direct HCD adoption letter PDF surfaced via search (title only, **not independently
    fetched/confirmed** beyond the snippet — flagged, not guaranteed live):
    https://www.ci.millbrae.ca.us/DocumentCenter/View/1587/sma-millbrae-adopt-in-030124
  - Contact: Planning Division, planning@ci.millbrae.ca.us, 650-259-2341.
- **Local Density Bonus Ordinance — in progress, adoption status unconfirmed:** Search
  confirmed (via a `ci.millbrae.ca.us` Calendar entry) a "Virtual Collaborative Session
  on Consideration of a Local Density Bonus Ordinance," **April 16, 2025**, hosted by the
  Community Development Department, tied to inclusionary housing policy updates.
  Calendar URL: https://www.ci.millbrae.ca.us/Calendar.aspx?EID=1464 — **whether this
  ordinance has since been adopted was not confirmed**; no adoption record surfaced in
  this pass.
- **Builder's Remedy:** No Millbrae-specific Builder's Remedy project or dispute was
  found. Only general statewide commentary on AB 1893 (signed Sept 19, 2024, effective
  Jan 1, 2025, codifying the Builder's Remedy into the Housing Accountability Act)
  surfaced — not Millbrae-specific, not included as a citation.
- **Zoning amendments (pre-adoption context):** A 2022 C/CAG document, "Millbrae Zoning
  Amendments Draft City Edits 9.20.22," suggests zoning-amendment work tied to Housing
  Element rezoning sites was underway in 2022, likely feeding the certified 6th Cycle
  element:
  https://ccag.ca.gov/wp-content/uploads/2022/10/5A5-Millbrae-Zoning-Amendments-Draft-City-Edits-9.20.22.pdf
  No confirmed 2025/2026 zoning ordinance amendment was found beyond the density bonus
  ordinance consideration above.
- **Municipal code host:** **eCode360 (General Code)** — search snippet shows the code
  reported current "through 03-24-2026," hosted at https://ecode360.com/MI4538 (title/
  currency banner **not independently fetch-confirmed** — see access notes below). A
  secondary/legacy host also exists: **Code Publishing Co.**,
  https://www.codepublishing.com/CA/Millbrae/.
  - Individual eCode360 subsection URLs appeared in search results (e.g.
    https://ecode360.com/47414806, https://ecode360.com/47414547) and individual Code
    Publishing Co. chapter pages also surfaced (e.g.
    https://www.codepublishing.com/CA/Millbrae/html/Millbrae08/Millbrae0860.html, tree
    protection chapter) — none of these were confirmed fetchable in this pass (see below).
- **Access notes (code hosts):** **Both `ecode360.com/MI4538` and
  `codepublishing.com/CA/Millbrae/` returned HTTP 403 Forbidden on direct WebFetch** —

- **Est. pull effort:** **Medium–High.** The Housing Element page itself is a clean,
