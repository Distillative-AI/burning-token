# Burlingame, CA — Housing Law Eligibility Snapshot (as of Sept 2026)

## Current Compliance Status (Housing Element)

**COMPLIANT.** HCD determined Burlingame's 6th Cycle (2023-2031) Housing Element met statutory
requirements and would substantially comply with State Housing Element Law upon adoption and
submittal (Gov. Code §65585). The Burlingame City Council **adopted** the Housing Element on
**Dec 18, 2023**. Burlingame did not appear on the Sept 2024 8-jurisdiction San Mateo County
non-compliance roster, nor on the narrower late-2025 list (unincorporated County + Half Moon Bay
only) — consistent with continuous compliance from adoption through Sept 2026.

HCD's statewide implementation/APR dashboard
(https://www.hcd.ca.gov/planning-and-community-development/housing-open-data-tools/housing-element-implementation-and-apr-dashboard)
was checked but does not expose a fetchable per-jurisdiction compliance table — status above is
sourced from the City's own Housing Element page and HCD's compliance-finding letter language,
not a direct dashboard screenshot/table.

## SB9 / SB35 / SB10 Status

**SB9 (lot splits):** Burlingame has a **local implementing ordinance** — the "Two-Unit
Residential Overlay" (Burlingame Municipal Code §25.20.080), applied in the R-1 (Low Density
Residential) zoning district. Confirmed local restrictions:
- **Owner-occupancy requirement**: applicant must affidavit an intent to use one resulting unit
  as a principal residence for **at least 3 years** from approval.
- Objective standards include a minimum unit floor area (units must be at least 800 sq ft) and
  maximum height limits.
- **ADUs/JADUs are not permitted** on parcels created via an SB9 urban lot split in Burlingame —
  a materially restrictive local condition beyond bare state-default SB9.
- No historic-district exclusion was found in the search results (UNCONFIRMED either way).

**SB35:** No primary current-cycle HCD SB35 determination table was retrieved confirming
Burlingame's tier (10% vs 50% affordability) for the Sept 2026 cycle — **UNCONFIRMED**. No
specific SB35 project filings were found for Burlingame's downtown/Broadway corridor despite a
targeted search. What WAS found: the City has initiated a **Broadway Specific Plan** process
tied to the Broadway Caltrain grade-separation project (a CPUC top-priority at-grade crossing
elimination) — this is a planning/infrastructure process, not an SB35 streamlined-ministerial
housing filing, and should not be conflated with SB35 activity. No evidence of any filed SB35
application in Burlingame was found in this pass.

**SB10:** **No evidence found of Burlingame adopting a local SB10 resolution/ordinance** mapping
transit-rich or jobs-rich parcels for up to 10 units/parcel. Confirmed as a negative/absence
finding from search, not a directly-sourced council statement of non-adoption — a direct check of
Burlingame council resolution archives would be needed to fully rule out.
